# 🧠 IA Auto-Evolutiva - Sistema Completo

Sistema de IA que aprende programação automaticamente, evoluindo sem intervenção humana.

## 🚀 Início Rápido

### Windows:

### Terminal:
```bash
python menu.py
```

## 📁 Estrutura do Projeto

```
Criando_IA_Inteligente/
│
```

## 💡 Modos de Operação

### 1. Chat Interativo (`chat_system.py`)
- Interface gráfica para conversar
- Testar capacidades em tempo real
- Ver status e métricas
- Forçar evolução manual

### 2. Evolução Autônoma (`autonomous_evolution.py`)
- Roda 24/7 sem supervisão
- Aprende continuamente
- Gera dashboard automático
- Backup diário

### 3. Sistema Integrado (`integrated_system.py`)
- Terminal interativo
- Bootstrap inicial
- Teste rápido

## 🎯 Como a IA Evolui

1. **Pesquisa**: Busca código em APIs (GitHub, etc)
2. **Aprendizado**: Extrai padrões e técnicas
3. **Experimentação**: Gera variações de código
4. **Avaliação**: Mede qualidade automaticamente
5. **Evolução**: Combina melhores soluções
6. **Repetição**: Ciclo contínuo 24/7

## 📊 Métricas e Monitoramento

Arquivos gerados automaticamente:
- `dashboard.html` - Painel visual
- `evolution.log` - Log detalhado
- `knowledge.json` - Base de conhecimento
- `neural_weights.npz` - Pesos da rede

## 🔧 Configuração

Edite `auto_config.json` para ajustar:
- Tamanho da população
- Taxa de mutação
- Frequência de ciclos
- Limites de memória

## 📈 Progressão Esperada

- **Dia 1**: Aprende sintaxe básica
- **Semana 1**: Domina estruturas fundamentais
- **Mês 1**: Cria soluções complexas
- **Mês 3**: Desenvolve próprias bibliotecas

## ⚡ Dicas

1. **Deixe rodando**: Evolução é contínua

4. **Não interrompa ciclos**: Podem durar horas

## 🆘 Problemas Comuns

### IA não evolui
- Verifique `evolution.log`
- Aumente taxa de mutação em `auto_config.json`

### Erro de API
- Sistema auto-ajusta delays
- Verifica rate limits automaticamente

### Memória alta
- Ativa poda automática
- Reduz `memory_size` na config
